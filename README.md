# 🏰 アグリキングダム

農業高校で学ぶ **野菜・草花・果樹・作物** の知識を、農業クラブの「農業鑑定競技」形式の問題で学びながら、自分だけの王国（畑）を育てていく学習ゲームです。

## あそび方

1. **📝 鑑定**：問題に正解すると、種・苗・施設などのアイテムが手に入ります。
   - コンボが続くほどレアアイテムが出やすくなり、**5コンボでFEVER（報酬2倍）**。
   - 間違えた問題は **復習ノート** にたまり、克服するとボーナス報酬がもらえます。
2. **🏰 王国**：アイテムを好きなマスに置いて育てます。育ったら収穫してコインとXPをゲット。
   - 果樹は一度植えると何度でも収穫できます。
   - 育成中に **🐛病害虫** が発生することも。タップして問題に正解すると撃退でき、作物が一気に成長します。
   - 施設（スプリンクラー・ミツバチの巣箱・かかし など）は周囲のマスに効果があります。配置を工夫しよう。
3. **🗺️ 領土拡張**：コインを集めて **昇格試験（5問中4問正解）** に合格すると、領土が広がります（最大10×10）。
4. **🏅 鑑定競技モード**：全分野から20問・1問20秒の本番形式。S〜Cのランクで評価されます。
5. **⚔️ 日替わりボス**：ヨトウムシ将軍・いもち病の魔王・暴れイノシシなどが毎日襲来。正解で攻撃（コンボで威力UP・会心の一撃あり）、まちがえるとハートが減ります。
6. **🗓️ 旬**：現実のカレンダーで旬をむかえている作物は、成長1.5倍・コイン1.5倍。季節に合った作物を植えよう。
7. そのほか、デイリーミッション・ログインボーナス・図鑑・実績・称号があります。

> アイテムは基本的に **問題を解くことでしか手に入りません**。

## 起動方法

ビルド不要です。`index.html` をブラウザで開くだけで動きます（Chromebook・iPad・PC対応）。

GitHub Pages で公開すると、生徒はURLにアクセスするだけで遊べます：
リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存。

GitHub Pages など http(s) で公開した場合は、オフラインでも動作し、ホーム画面に追加してアプリのように使えます（PWA）。

セーブデータは各端末のブラウザ（localStorage）に保存されます。端末を変えるときは「記録 → データ引き継ぎ」のコードを使います。

## クラウド保存・クラスランキング・先生用ダッシュボード（Firebase）

`js/firebase-config.js` に Firebase の設定を書くと、次の機能が使えるようになります（未設定ならこの端末だけに保存）。

- **Googleログイン＋クラウドセーブ**：どのPCからでも続きができる
- **クラスランキング**：クラスコードで参加。今週の正解数・累計正解・鑑定競技・レベル・図鑑・ボス討伐
- **先生用ダッシュボード**（`teacher.html`）：クラス作成、生徒ごとの解答数・分野別正答率・苦手分野、つまずきが多い問題TOP15、CSV出力

設定手順は **[docs/FIREBASE_SETUP.md](docs/FIREBASE_SETUP.md)** を参照してください。

## 問題の追加・修正（先生向け）

`js/data/questions.js` を編集します。

```js
{ id: 'v32', f: 'veg', q: '問題文', c: ['正解', 'ハズレ1', 'ハズレ2', 'ハズレ3'], e: '解説' },
```

- `f`：`basic`（共通）/ `veg`（野菜）/ `flower`（草花）/ `fruit`（果樹）/ `crop`（作物）/ `food`（食品製造）
- `c` は **最初の選択肢が正解**（表示時にシャッフルされます）
- 写真を使った鑑定問題にしたい場合は `img: 'img/ファイル名.jpg'` を追加

アイテム（作物・施設）・旬の月・ボスは `js/data/items.js` で追加・調整できます。

## ファイル構成

```
index.html          画面の骨組み
css/style.css       見た目
js/data/questions.js 問題データ
js/data/items.js     アイテムデータ
js/core.js          セーブ・XP・ドロップ抽選・ミッション・実績
js/effects.js       効果音・紙吹雪・モーダルなどの演出
js/quiz.js          クイズ（修行・復習・鑑定競技・昇格試験・病害虫）
js/farm.js          王国（配置・成長・収穫・領土拡張）
js/screens.js       鑑定メニュー・倉庫・図鑑・記録
js/main.js          起動・画面切り替え・PWAインストール
js/cloud.js         Firebase：ログイン・クラウドセーブ・クラス参加・ランキング
js/firebase-config.js  Firebase の設定（先生が編集）
teacher.html / js/teacher.js / css/teacher.css  先生用ダッシュボード
firestore.rules     Firestore のセキュリティルール
sw.js / manifest.webmanifest / icon-*.png  オフライン対応（PWA）
```
