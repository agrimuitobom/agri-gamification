# Firebase 設定手順（先生向け）

所要時間：15〜20分。無料プラン（Spark）で動きます。

## 1. Firebase プロジェクトを作る
1. https://console.firebase.google.com/ に先生の Google アカウントでログイン
2. 「プロジェクトを作成」→ 名前（例：`agri-kingdom`）を入力
3. Google アナリティクスは **オフ** でOK →「プロジェクトを作成」

## 2. Google ログインを有効にする
1. 左メニュー「構築」→「Authentication」→「始める」
2. 「Sign-in method」タブ →「Google」→ **有効にする** → サポートメールを選んで保存
3. 「Settings」タブ →「承認済みドメイン」→「ドメインの追加」で
   **`agrimuitobom.github.io`** を追加

## 3. データベース（Firestore）を作る
1. 左メニュー「構築」→「Firestore Database」→「データベースの作成」
2. ロケーション：**`asia-northeast1`（東京）**
3. 「本番環境モードで開始」を選んで作成
4. 「ルール」タブを開き、リポジトリの **`firestore.rules`** の中身を全部貼り付け
5. `'sensei@example.ed.jp'` の部分を **先生のメールアドレス** に書き換えて「公開」
   （先生が複数いる場合は `'a@xx.ed.jp', 'b@xx.ed.jp'` のようにカンマ区切り）

## 4. Web アプリを登録して設定値をもらう
1. 左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」で **`</>`（ウェブ）** を選ぶ
2. アプリのニックネーム（例：`agri-kingdom-web`）を入力して登録（Hosting はチェック不要）
3. 表示される `const firebaseConfig = { ... }` の中身をコピー

## 5. ゲームに設定を書き込む
`js/firebase-config.js` を開いて編集します（GitHub の画面上で鉛筆アイコンから編集できます）。

```js
AK.FIREBASE_CONFIG = {
  apiKey: '....',
  authDomain: '....firebaseapp.com',
  projectId: '....',
  storageBucket: '....',
  messagingSenderId: '....',
  appId: '....',
};

AK.TEACHER_EMAILS = ['先生のメールアドレス'];   // firestore.rules と同じもの
AK.ALLOWED_DOMAIN = '学校のドメイン';           // 例：'xxx.ed.jp'（生徒以外のログインを防ぐ）
```

> この設定値は Web に公開されても問題ない情報です。データの保護は手順3のルールで行っています。

保存（コミット）すると、1〜2分で GitHub Pages に反映されます。

## 6. クラスを作って生徒に伝える
1. `https://agrimuitobom.github.io/agri-gamification/teacher.html` を開いて先生のアカウントでログイン
2. 「＋ クラスを作成」→ クラス名を入力
3. 表示された **6文字のクラスコード** を生徒に伝える
4. 生徒はゲームにログイン → クラスコードを入力 → ランキングに参加

## 7. 生徒の PC にアプリとしてインストール（任意）
Chrome / Edge でゲームを開き、アドレスバー右端のインストールアイコン、またはゲーム内「記録」→「📲 アプリとしてインストール」。
デスクトップやスタートメニューから全画面で起動できます。

## よくあるトラブル
| 症状 | 対処 |
|---|---|
| ログインのポップアップが「承認されていないドメイン」 | 手順2-3 の承認済みドメインを確認 |
| 生徒がログインできない（管理者によりブロック） | Google Workspace の管理者に「サードパーティ製アプリのアクセス」でこのアプリ（Firebase の OAuth クライアント）を **信頼済み** にしてもらう。18歳未満に設定された生徒アカウントでは特に必要です |
| 先生ページで「読み込めませんでした（permission）」 | `firestore.rules` と `firebase-config.js` の両方に先生のメールが入っているか確認 |
| ランキングに自分しか出ない | 全員が同じクラスコードで参加しているか確認 |
